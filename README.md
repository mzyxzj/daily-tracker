## 2.8.0 · 分级归入文化 + 全条目可编辑（Empire-V2.1 续）

两条改动：**「分级」从医疗搬到文化**，以及**文化 / 医疗的每一条都能编辑、删除、保存**。

### 分级为什么搬到文化

分级讲的是「这个电量下，什么娱乐能做、什么不能碰」——它约束的是**文化消费**，
不是医疗处置。所以现在它是「文化」的第四个板块：

文化：**内容引进 / 再创作 / 流量算法 / 分级**

- 卡片显示档位名、电量区间、一句话备注、「可以：」「别碰：」；
- 医疗页记过电量后（写入 `ui_states.medical_battery_now`），这一档整卡高亮并标「你在这里」；
- 每档右上角「⋯」可**编辑**（名称 / 区间 / 可以 / 别碰 / 备注）或**删除**，
  底部「新增一档」可自己加档位；至少保留一档，删空了可点右上角「恢复内置分级」；
- 内置四档只在表为空时落一次；从 v12 升级的用户，原来 `medical_grades` 里
  **改过的文案会原样迁到 `culture_grades`**，不会重置成默认。

医疗页删掉分级后只剩三块：**预防 / 急救 / 治疗**，血条与急救入口不变。

### 全部条目：编辑 / 删除 / 保存

| 模块 | 条目 | 编辑 | 删除 | 说明 |
|---|---|---|---|---|
| 文化 | 资源库 | 名称 + 备注 | 连同库内内容一起删 | 删掉后维度进黑名单，不自动复活 |
| 文化 | 内容 | 标题 / 链接 / 归库 / 类型 / 标签 / 备注 / 封面 / 时长 | 单条删 | 编辑与新增共用同一个表单 |
| 文化 | 工具包 | 标题 / 目标 / 步骤增删勾选 / 模板正文 | 列表右上角「⋯」删 | 详情页每步都能改，改完即存 |
| 文化 | 优质源 | 名字 / 链接 / 权重 / 备注 | 单条删 | |
| 文化 | 分级 | 名称 / 区间 / 可以 / 别碰 / 备注 | 单档删（至少留一档） | 可新增、可恢复内置 |
| 医疗 | 预防预案 | 名字 / 触发信号 / 步骤 | 删（内置的停用，可恢复） | 当天打卡不受影响 |
| 医疗 | 急救预案 | 名字 / 触发信号 / 步骤 / 生效档位 | 同上 | 全屏急救按改后的步骤走 |
| 医疗 | 恢复手段 | 名字 / 耗时 / 预计恢复 | 同上 | 排序会跟着新数据变 |

所有写操作都直接落 sqflite，返回列表立即刷新；没有「只改内存、重启就回退」的路径。

### 数据与兼容
- DB 12 → **13**，新增 `culture_grades`；`CultureDb.ensureTables` 负责建表、迁移、种子。
- 迁移顺序：`culture_grades` 为空 → 读旧 `medical_grades` 原样复制 → 仍为空才落内置四档。
- 老表 `medical_grades` 保留不删（只读不写），回退到 V2.1 旧包也不会报错。
- `flutter analyze lib`：新增代码 0 error；34 个测试全绿（文化 14 + 医疗 14 + 分级迁移/CRUD 6）。

## 2.7.0 · 医疗模块（Empire-V2.1 续）

「医疗建设」变成和「规划 / 文化」同级的第七个 tab：**医疗**。底部导航：
查找 / 家庭 / 今日 / 帝国 / 规划 / 文化 / **医疗**。

页面顶部常驻**前额叶电量血条**（0–100%），记一次就有数：最近值、今日最低、急救次数、
治疗次数，以及最近 7 天每天的最低电量小柱图。低于 15% 整条变红，直接给「进入急救」。
对应导图四条分支，正好是四段：

### 1. 预防 · 在掉下去之前拦一道
内置三条：**防止前额叶电量过低**、**防止暴饮暴食**、**防止恐慌式学习 / 做事**。
每条都拆成「触发信号 + 3 个动作」：
- 触发信号写成你能感知的现象（「连续开会 2 小时后看同一行字三遍」），
  不写抽象状态；
- 信号一出现就执行，不靠意志力硬扛；
- 今天做到就点一次，同一天同一条只算一次。

可以自己加预案、改步骤；内置的删掉后可从菜单「恢复内置预案」找回。

### 2. 急救 · 已经崩了就别分析
三条预案：**电量低于 15%**（严格对应导图四步：放空大脑 / 放弃任何高耗能娱乐 /
不提任何提议、不做决定 / 只执行最低限度日程，维持秩序稳定）、**暴饮暴食后的止损**、
**恐慌式学习 / 熬夜的紧急止损**。

点「现在启动」进**全屏急救模式**：深红底、一次只显示一步、只有一个「下一步」按钮，
把决策次数降到 0；最后一步是「做完了，回到最低日程」。血条 ≥15% 时，红色那条按钮
显示「血条 ≥15% 时不需要它」，避免平时误触。

### 3. 治疗 · 先补电，再谈效率
8 种恢复手段（闭眼放空 / 户外快走 / 力量训练 / 晒太阳 / 冷水洗脸 / 23:00 前上床 /
和人聊 15 分钟 / 断网 30 分钟），每种带预计恢复与耗时。
- 排序不是固定的：按「预计恢复 ÷ 耗时」算分，电量见底时只把 10–20 分钟内、
  能躺着做的推到前面；
- 点「用了」记录「用前 X% → 用后 Y%」，实际恢复为负会直接提示「记下来，下次别选它」；
- 做得越多，排序越贴近你自己的数据。

### 4. 分级 · 不是所有娱乐都适合所有电量
四档（绿灯 ≥60 / 黄灯 30–59 / 橙灯 15–29 / 红灯 <15），每档写清「可以做什么」
和「别碰什么」。当前电量所在档位整卡高亮并标「你在这里」。四档内容都可编辑，
红灯区默认：可以躺下 / 闭眼 / 喝水 / 洗漱，别碰一切屏幕 / 任何提议 / 任何决策。

### 数据与兼容
- DB 11 → **12**，新增 `medical_plans` / `medical_grades` / `medical_logs` /
  `medical_events`，老库升级自动补齐，不动原有表。
- 医疗信号写入 `ui_states`：`medical_battery_now`、`medical_battery_min`、
  `medical_emergency_today`、`medical_prevent_today`、`medical_treat_today`，
  帝国页可直接读血条。
- 没有新增依赖。
- `flutter analyze lib`：新增代码 0 error；28 个测试全绿（文化 14 + 医疗 14）。

## 2.6.0 · 文化模块（Empire-V2.1）

「文化建设」从导图里的一行字，变成和「规划」同级的第六个 tab：**文化**。底部导航：
查找 / 家庭 / 今日 / 帝国 / 规划 / **文化**。

对应导图的三个子模块，页面顶部就是三段：

### 1. 内容引进 · 建立优质资源库
- **按聚焦维度建库**：首次进入落 6 个内置库（健身 / 家庭 / AI / 炼心 / 摄影 / 其他）；
  之后每次进入会把「今日 · 战略聚焦」里出现过的维度自动补成同名库，不重复建。
  手动删掉的库进 `culture_hidden_dims` 黑名单，维度还在也不会自己复活。
- **至少能存链接、能打开**：一条内容 = 链接 + 一句话标题（粘贴自动拆 URL 和标题），
  平台从域名识别（B站 / 抖音 / YouTube / 小红书 / 公众号 / 知乎 / GitHub / 微博 / X / Notion）。
- **两种信息流**：B 站式横版卡（16:9 封面 + 两行标题 + 时长 + 平台），抖音式竖版两列
  （9:16 封面为主）；再加一个紧凑列表。封面填 URL 就用图，不填用平台色渐变 + 首字兜底。
- **10 秒找到**：搜索框输入即筛（标题 / 标签 / 来源 / 备注 / 链接），筛选「全部 / 未看 /
  收藏 / 看过」，排序规则是收藏 > 未看 > 打开次数 > 最近打开。点卡片直接打开，
  不先进详情页。

### 2. 再创作 · 变成能直接用的工具包
- 内容长按 →「转成工具包」，默认生成三步骨架（标 3 个能用的点 / 改写成自己的话 /
  套到一个真实场景）。
- 工具包详情：可改标题、目标、任意增删步骤、勾选完成、写模板正文，进度条实时走。
- 「复制 Markdown」按 `# 标题 / > 目标 / - [x] 步骤 / ## 正文` 导出，粘到任何笔记都能用；
  也能直接分享。

### 3. 流量算法 · 直达优质资源
- 优质源：名字 + 链接 + 权重（1–5 星）+ 为什么值得看，按权重排序，一键「直达」。
- 「今日 3 条」：高权重平台 + 收藏 + 没看过的，各库轮流取，避免一天全是一个库；
  「换一批」重排，看完的不再推。
- 内置浏览器：Android / iOS 用 WebView 在 App 内看完（带进度条、收藏、标记看完、
  转工具包）；站点拦截 WebView 时给「用浏览器打开」兜底，链接不丢。

  `culture_sources`，老库升级时 `CultureDb.ensureTables` 自动补齐，不动原有表。

## 2.5.4 · 聚焦去重 + 模板可编辑（Empire-V1.3）

### 战略聚焦为什么会重复
`FutureBuilder(future: _load())` 写在 `build` 里，任何一次 `setState`（勾选、记笔记、折叠）
都会新建一个 Future；几条 `_load()` 并发跑「未完成顺延」，都先查「今天有没有这条」→ 都查到
空 → 各插一条，于是同一条聚焦出现 2～4 份。

四层修复：
1. **加载复用**：`_load()` 对同一日期复用在飞的 Future（`_loadingFuture` / `_loadingDate`），
   顺延逻辑不再并发执行；日期切换才重开。
2. **去重键修正**：顺延判重从「标题」改成「维度 + 下一步」。原来的键是维度，同维度下的
   多个不同下一步会被误判成同一条而丢掉。
3. **插入幂等**：`ConflictAlgorithm.ignore` + 每处理一条立刻置 `rolled = 1`，缩小窗口。
4. **库层兜底**：DB 版本 9 → 10，升级时 `AppDatabase.dedupeFocusItems()` 按
   `(date, title, next_step)` 合并历史重复（已勾选的优先保留、较长的备注并过去），
   再建唯一索引 `idx_focus_unique`。手动新增重复项改为合并并 SnackBar 提示。

### 模板全部可编辑
- 4 条内置模板首次运行并入 `ui_states.deepseek_presets`，与自定义模板同等对待：
  可改名、改角色、改指令、删除（删除有二次确认）。
- 管理页底部新增「恢复内置」，删错了能一键补回；「新建预设」用当前角色 + 指令存一条。
- `deepseek_presets_seeded` 标记保证内置模板只并入一次，删掉后不会下次启动又出现。
- 菜单标题改为「模板 · 可编辑」，避免「内置 = 只读」的误解。

## 2.5.3 · 反思指令外置 + 预设可编辑（Empire-V1.2）

### 首轮正文只发数据
`_firstPayload()` 末尾那段「请据此做今日反思：先给 3 条核心判断；再分板块分析…」已删除。
现在「将发送给 DeepSeek 的内容」只有三段：`【日期】` / `【今日记录】` / `【战略聚焦】`。
预览弹窗底部会显示当前生效的角色与预设名，避免「看不到指令」的疑惑。

### 分析方式收进角色与指令
- 默认角色：`第一性原理复盘官`。
- 默认指令（`kDefaultPrompt`）写死了输出骨架：
  1. 3 条核心判断，每行 ≤30 字，必须是明天可验证的事实判断；
  2. `### 精力与执行的错配` —— 峰谷时段、难任务位置、代价、纠偏；
  3. `### 战略聚焦的推进实况` —— 逐项：推进到哪步 / 是否达标准 / 卡在能力还是时间；
  4. `### 系统性风险` —— 只挑连续三天会崩的结构性隐患，写触发条件；
  5. `### 明日最小动作` —— 恰好 3 条，≤30 分钟，带时间点与完成判据。
- 数字要给具体值与方向，没记录写「未记录」，不要猜。
- 老配置自动升级：文本等于 `kLegacyPrompt` 或 `kV11Prompt` 时替换为新默认。

### 预设
- 内置 4 条只读模板：帝国日课复盘（默认）/ 代谢与营养精算师 / 精力与执行教练 / 战略聚焦推进官。
- 「保存当前为预设…」把当前角色 + 指令存进 `ui_states.deepseek_presets`（同名覆盖）。
- 「管理我的预设…」支持改名、改角色、改指令、删除、点击整行直接套用。
- 套用后会立刻写回 `deepseek_ai_config`，下次打开面板自动带出上次用的那套。

## 2.3.0 · 帝国模块进主界面

### 模块结构
帝国与「查找 / 家庭 / 今日 / 规划」同一层级，作为底部第 4 个 Tab（`lib/empire_page.dart`）。

- **主模块页**：整屏只留一个 3D 领地 + 两张关键参数子模块 + 一框三条纪事。
  - 领地：`lib/empire_assets.dart` 里内嵌的 L07 渲染图（640×640 WebP，由已生成的 GLB 离线渲出），缓慢浮动 + 落地投影；顶部等级胶囊、右上复利乘数、底部距下一级进度。
  - 繁荣度子模块：大数字 + 十年曲线缩略 + 日均增量，点进去是详情页。
  - 乘数效应子模块：复合乘数 + 六维构成色条 + 突破项数，点进去是对比页。
  - 纪事：卡片只留最近 3 条（小字、色标区分战争/晋升/突破），点开是全部 47+ 条。
- **繁荣度页**：领地平面图（九级台地 / 六分区 / 主街 / 建筑群 / L07 界线）+ 成长曲线
  （30 天 / 90 天 / 1 年 / 3 年 / 10 年，自动或对数轴，等级线与穿越点）+ 九级形态进程条。
- **乘数效应页**：六维总乘数横向对比（条长按增量比例），点某个维度就展开该维度
  **最新已突破的下一步**（完成标准、日期、乘数），其余维度淡出到 40%；下方补最近 5 条突破。

### 口径（`lib/empire_data.dart`）
- 每日基础流量 500 × 当日连乘，按 3650 天推演 → 繁荣度曲线与九级门槛（×5 递增）。
- 维度总乘数 = 该维度下所有「已突破」下一步的乘数逐个相乘；复合乘数 = 六个维度总乘数再相乘。
- 只统计 `focus_items` 里 `done = 1` 的条目；取消勾选会自动退回。
- 本地还没有「已突破」条目时，用 `lib/empire_assets.dart` 内嵌的示例数据撑起界面，页头标「示例推演」。
- 每次切到帝国 Tab 或下拉刷新都会重新读库。
