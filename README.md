# daily-tracker

本仓库只放源码（lib / pubspec / CI），Android 工程由 CI 里的 `flutter create` 生成。

## 4.0.0 · 一个流，一个播放器，复制就弹（Empire-V4.0）

这一版把 3.0 的四个 tab 全部拆掉，合成**一件事**：进来就看，往下刷。

### 1. 文化首页 = 全屏推荐流
- 竖向 `PageView`，一屏一条，上下滑。封面铺满 + 压暗，标题、作者、平台、分级、
  「为什么推这条」都在底部，右侧是抖音式竖排（收藏 / 看完 / 改写 / 更多）。
- 没有 tab，没有宫格，没有「先选库再看内容」。库只是推荐权重的一个因子。
- 顶部一个电量胶囊：`45% · 黄灯区`，点一下切换「只看这一档 / 看全部」。
- 排序规则（`lib/content_feed.dart` 的 `buildCultureFeed`）：
  同档 +92、更轻的档 +44、比当前档更耗电默认不进流；今日聚焦 +30、未看 +18、
  收藏 +10、30 天内新鲜度加权；**反复打开过的减分**；
  相邻两页强制换库（内容全来自一个平台时才允许同库连着）。
- **修正了 3.0 的一个真 bug**：原逻辑把「比当前档更轻」的内容当成了「更耗电」过滤掉，
  导致黄灯区看不到绿灯内容。现在按 tier 数字越大越耗电处理。

### 2. 引进 / 分级 / 库 / 再创作 → 右侧可隐藏侧边栏
点右上角滑块图标（或从右边缘滑）拉出，全部在一屏里：
- 复制即弹状态 + 电量；
- 从剪贴板整理 / 手动填一条；
- 四档分级（点一档直接改区间和文案，可新增）；
- 库列表（可新建，显示每个库多少条）；
- 工具包入口 + 最近存的 6 条。
**优质源已删除**（不再维护 UP 主权重表）。

### 3. 内置播放器，不跳走
- 点「在这里看」推到全屏 WebView，`dart:io` 抓不到的东西在这里看。
- **沉浸模式**：注入 CSS 把平台的推荐流、评论区、侧栏、底部切换全部隐藏，
  `html,body{overflow:hidden}` 防止误滑到下一个视频。你看的就是这一条，看完就退。
- **登录**：右上角「登录」在同一个 WebView 里打开 B站 / 抖音 / 小红书 / 知乎登录页，
  cookie 由系统 WebView 持久化，登录一次以后都能直接看。
- 底部操作条：收藏 / 看完 / **取正文** / **生成工具包**；可一键隐藏成沉浸模式。
- 抓正文优先 `document.body.innerText`，失败退 `B站 view 接口 desc` → `og:description`，
  存进 `culture_items.content_text`（v15 新列）。

### 4. 再创作 = DeepSeek 工具包工作室
- 从任意一条内容进入：左边是抓到的正文，中间是「我自己的笔记」和「我想要什么」，
  下面一个按钮让 DeepSeek 生成。
- 提示词要求它输出：一句话判断 → 3-5 个 30 分钟内能动手的步骤 → 至少一个可复制模板/清单
  → 2 条「听起来对但别照搬」 → 一句下一步。不是摘要。
- 生成结果流式显示，可复制、可存成工具包（自动把编号步骤解析成可勾选 steps）。
- API Key 存在应用文档目录（不进数据库备份），没填过就在这里填一次。

### 5. 复制链接就弹窗（Android 原生）
Android 10 起普通 App 在后台读不到剪贴板，所以「复制那一刻就问我」只能由系统级组件做：
- `.android-inject/ClipWatchService.kt`：**无障碍服务**监听剪贴板，判断像不像分享链接，
  用 `TYPE_ACCESSIBILITY_OVERLAY` 在屏幕上方弹一条「这条要整理进「文化」吗？整理 / 略过」。
  这个窗口类型是无障碍服务专属的，**不需要再申请「显示在其他应用上层」**。
- 点「整理」→ 带 Intent extra 启动 App → 直接进引进表单。
- 关闭无障碍或没开时，仍有三条兜底：系统分享面板选本 App（`ACTION_SEND`）、
  点开 http 链接（`ACTION_VIEW`）、切回 App 时前台读一次剪贴板。
- 首次在侧边栏点「复制链接就弹窗（未开启）」会解释清楚再跳系统设置。

### 构建注意
- `.android-inject/` 是给 CI 用的：`flutter create` 生成 Android 壳之后，
  `patch.py` 把 Kotlin 服务、`res/xml/clip_service.xml` 和 manifest 改进去（幂等）。
- 新增依赖：无（网络仍用 `dart:io`；`url_launcher` 已移除）。
- 数据库 14 → **15**：`culture_items` 增 `content_text`。
- 69 个测试全绿（新增 13 个推荐流 / prompt 测试）。


## 3.0.0 · 内容引进 / 分级推荐 / 库首页（Empire-V3.0）

这一版把「内容引进 + 流量算法 + 分级」缝成了一条流水线：**复制 → 确认 → 归档 → 按电量喂给你**。

### 1. 复制链接就能引进
在抖音 / B站 里点「分享 → 复制链接」，切回 App 会自动弹一条确认：「检测到一条内容，要引进吗」。
点「引进」后：

- **封面、标题、作者、时长自动抓**：B站走公开 `view` 接口（短链先跟随跳转拿 BV 号），
  抖音走 `iteminfo`，都失败就用网页 `og:meta`，再失败就用分享文案里的标题 + 平台色块。
- 你**只需要点一个分级标签**（绿 / 黄 / 橙 / 红灯，或「先不标」），库会按聚焦维度自动猜，
  猜错再点一下改。标签从分享文案里的 `#话题` 自动带过来。
- 同一链接只问一次；已经入库的会提示「保存会更新它」，不会存出两条。
- 关闭方式：文化页右上角菜单「剪贴板自动识别：开/关」，或确认条上的「以后别自动弹」。
- **不做后台轮询**：只在「从别的 App 切回来」和「点开文化 tab」时各读一次剪贴板（2.5s 节流），
  避免 Android 12+ 反复弹系统粘贴提示。

### 2. 分级和电量真正连起来
「流量算法」不再按时间倒序凑三条，而是：

1. 读医疗页写的 `medical_battery_now`，按分级表落到**当前档**；
2. 只推这一档能承接的内容：同档 +90，更轻的档 +46，比这档更耗电的直接不进候选；
3. 今日「战略聚焦」里的维度 +32，未看 +14，收藏 +8，优质源平台加权；
4. 同一库最多 2 条，「换一批」用确定性轮转，不会抖成随机；
5. **红灯区（<15%）** 会把 `forbid` 摆到最上面，明说「现在不是看内容的时候」。

可以临时关掉「只看这一档」看别的档，也可以点「换一批」；头部卡片会写清「为什么推这些」。

### 3. 库首页：先进分区，再扫视频
- 「内容引进」第一屏是**库宫格**：每个库三张封面拼贴 + 条数 + 没看数，长按改名 / 删除，
  最后一个卡片是「全部内容」。库来自内置维度 + 战略聚焦出现过的维度，删掉的不会自动复活。
- 进库后是 **B站式 16:9 海报流**（两列，一屏 6 条），另有竖版 9:16 抖音流、横版卡片流。
- 顶部有**分级筛选条**（全部档 / 四档 / 未标级），加「全部 / 未看 / 收藏 / 看过」和
  排序（推荐 / 最新 / 收藏 / 时长从短到长），搜索框覆盖标题、标签、作者、平台、备注。
- 每条卡片都带分级小标签，点「⋯」可以「设置分级」，不用进编辑页。

### 数据与兼容
- 数据库 13 → **14**：`culture_items` 增 `grade_tier / author / ext_id / from_share` 四列，
  老库用 `PRAGMA table_info` 检查后 `ALTER TABLE`，旧条目和封面都不动。
- 新增 `lib/content_fetch.dart`（解析 / 抓取 / 推荐，纯函数可测）、`lib/content_intake.dart`
  （轮询器 + 确认条 + 引进表单）。无新增第三方依赖（网络用 `dart:io HttpClient`）。
- CI 已注入 `INTERNET` 权限，release 包可以直接抓封面。


## 2.7.0 · 医疗模块（Empire-V2.1 续）

「医疗建设」变成和「规划 / 文化」同级的第七个 tab：**医疗**。底部导航：
查找 / 家庭 / 今日 / 帝国 / 规划 / 文化 / **医疗**。

页面顶部常驻**前额叶电量血条**（0–100%），记一次就有数：最近值、今日最低、急救次数、
治疗次数，以及最近 7 天每天的最低电量小柱图。低于 15% 整条变红，直接给「进入急救」。
对应导图四条分支，正好是四段：

### 1. 预防 · 在掉下去之前拦一道
内置三条：**防止前额叶电量过低**、**防止暴饮暴食**、**防止恐慌式学习 / 做事**。
每条都拆成「触发信号 + 3 个动作」：
- 触发信号写成你能感知的现象（「连续开会 2 小时后看同一行字三遍」），
  不写抽象状态；
- 信号一出现就执行，不靠意志力硬扛；
- 今天做到就点一次，同一天同一条只算一次。

可以自己加预案、改步骤；内置的删掉后可从菜单「恢复内置预案」找回。

### 2. 急救 · 已经崩了就别分析
三条预案：**电量低于 15%**（严格对应导图四步：放空大脑 / 放弃任何高耗能娱乐 /
不提任何提议、不做决定 / 只执行最低限度日程，维持秩序稳定）、**暴饮暴食后的止损**、
**恐慌式学习 / 熬夜的紧急止损**。

点「现在启动」进**全屏急救模式**：深红底、一次只显示一步、只有一个「下一步」按钮，
把决策次数降到 0；最后一步是「做完了，回到最低日程」。血条 ≥15% 时，红色那条按钮
显示「血条 ≥15% 时不需要它」，避免平时误触。

### 3. 治疗 · 先补电，再谈效率
8 种恢复手段（闭眼放空 / 户外快走 / 力量训练 / 晒太阳 / 冷水洗脸 / 23:00 前上床 /
和人聊 15 分钟 / 断网 30 分钟），每种带预计恢复与耗时。
- 排序不是固定的：按「预计恢复 ÷ 耗时」算分，电量见底时只把 10–20 分钟内、
  能躺着做的推到前面；
- 点「用了」记录「用前 X% → 用后 Y%」，实际恢复为负会直接提示「记下来，下次别选它」；
- 做得越多，排序越贴近你自己的数据。

### 4. 分级 · 不是所有娱乐都适合所有电量
四档（绿灯 ≥60 / 黄灯 30–59 / 橙灯 15–29 / 红灯 <15），每档写清「可以做什么」
和「别碰什么」。当前电量所在档位整卡高亮并标「你在这里」。四档内容都可编辑，
红灯区默认：可以躺下 / 闭眼 / 喝水 / 洗漱，别碰一切屏幕 / 任何提议 / 任何决策。

### 数据与兼容
- DB 11 → **12**，新增 `medical_plans` / `medical_grades` / `medical_logs` /

## 2.5.4 · 聚焦去重 + 模板可编辑（Empire-V1.3）

### 战略聚焦为什么会重复
`FutureBuilder(future: _load())` 写在 `build` 里，任何一次 `setState`（勾选、记笔记、折叠）
都会新建一个 Future；几条 `_load()` 并发跑「未完成顺延」，都先查「今天有没有这条」→ 都查到
空 → 各插一条，于是同一条聚焦出现 2～4 份。

四层修复：
1. **加载复用**：`_load()` 对同一日期复用在飞的 Future（`_loadingFuture` / `_loadingDate`），
   顺延逻辑不再并发执行；日期切换才重开。
2. **去重键修正**：顺延判重从「标题」改成「维度 + 下一步」。原来的键是维度，同维度下的
   多个不同下一步会被误判成同一条而丢掉。
3. **插入幂等**：`ConflictAlgorithm.ignore` + 每处理一条立刻置 `rolled = 1`，缩小窗口。
4. **库层兜底**：DB 版本 9 → 10，升级时 `AppDatabase.dedupeFocusItems()` 按
   `(date, title, next_step)` 合并历史重复（已勾选的优先保留、较长的备注并过去），
   再建唯一索引 `idx_focus_unique`。手动新增重复项改为合并并 SnackBar 提示。

### 模板全部可编辑
- 4 条内置模板首次运行并入 `ui_states.deepseek_presets`，与自定义模板同等对待：
  可改名、改角色、改指令、删除（删除有二次确认）。
- 管理页底部新增「恢复内置」，删错了能一键补回；「新建预设」用当前角色 + 指令存一条。
- `deepseek_presets_seeded` 标记保证内置模板只并入一次，删掉后不会下次启动又出现。
- 菜单标题改为「模板 · 可编辑」，避免「内置 = 只读」的误解。

## 2.5.3 · 反思指令外置 + 预设可编辑（Empire-V1.2）

### 首轮正文只发数据
`_firstPayload()` 末尾那段「请据此做今日反思：先给 3 条核心判断；再分板块分析…」已删除。
现在「将发送给 DeepSeek 的内容」只有三段：`【日期】` / `【今日记录】` / `【战略聚焦】`。
预览弹窗底部会显示当前生效的角色与预设名，避免「看不到指令」的疑惑。

### 分析方式收进角色与指令
- 默认角色：`第一性原理复盘官`。
- 默认指令（`kDefaultPrompt`）写死了输出骨架：
  1. 3 条核心判断，每行 ≤30 字，必须是明天可验证的事实判断；
  2. `### 精力与执行的错配` —— 峰谷时段、难任务位置、代价、纠偏；
  3. `### 战略聚焦的推进实况` —— 逐项：推进到哪步 / 是否达标准 / 卡在能力还是时间；
  4. `### 系统性风险` —— 只挑连续三天会崩的结构性隐患，写触发条件；
  5. `### 明日最小动作` —— 恰好 3 条，≤30 分钟，带时间点与完成判据。
- 数字要给具体值与方向，没记录写「未记录」，不要猜。
- 老配置自动升级：文本等于 `kLegacyPrompt` 或 `kV11Prompt` 时替换为新默认。

### 预设
- 内置 4 条只读模板：帝国日课复盘（默认）/ 代谢与营养精算师 / 精力与执行教练 / 战略聚焦推进官。

## 2.3.0 · 帝国模块进主界面

### 模块结构
帝国与「查找 / 家庭 / 今日 / 规划」同一层级，作为底部第 4 个 Tab（`lib/empire_page.dart`）。

- **主模块页**：整屏只留一个 3D 领地 + 两张关键参数子模块 + 一框三条纪事。
  - 领地：`lib/empire_assets.dart` 里内嵌的 L07 渲染图（640×640 WebP，由已生成的 GLB 离线渲出），缓慢浮动 + 落地投影；顶部等级胶囊、右上复利乘数、底部距下一级进度。
  - 繁荣度子模块：大数字 + 十年曲线缩略 + 日均增量，点进去是详情页。
  - 乘数效应子模块：复合乘数 + 六维构成色条 + 突破项数，点进去是对比页。
  - 纪事：卡片只留最近 3 条（小字、色标区分战争/晋升/突破），点开是全部 47+ 条。
- **繁荣度页**：领地平面图（九级台地 / 六分区 / 主街 / 建筑群 / L07 界线）+ 成长曲线
  （30 天 / 90 天 / 1 年 / 3 年 / 10 年，自动或对数轴，等级线与穿越点）+ 九级形态进程条。
- **乘数效应页**：六维总乘数横向对比（条长按增量比例），点某个维度就展开该维度
  **最新已突破的下一步**（完成标准、日期、乘数），其余维度淡出到 40%；下方补最近 5 条突破。

### 口径（`lib/empire_data.dart`）
- 每日基础流量 500 × 当日连乘，按 3650 天推演 → 繁荣度曲线与九级门槛（×5 递增）。
- 维度总乘数 = 该维度下所有「已突破」下一步的乘数逐个相乘；复合乘数 = 六个维度总乘数再相乘。
- 只统计 `focus_items` 里 `done = 1` 的条目；取消勾选会自动退回。
- 本地还没有「已突破」条目时，用 `lib/empire_assets.dart` 内嵌的示例数据撑起界面，页头标「示例推演」。
- 每次切到帝国 Tab 或下拉刷新都会重新读库。

## 2.2.0 · 反思面板重做 / 战略聚焦改名

### 反思面板（新增 `lib/deepseek_sheet.dart`）
- 改成气泡式多轮对话：首轮出结论，之后可就任意关注点继续追问，历史会一并发给模型。
- 新增「最终结论」：把整段对话收口成「重点关注 · 详细解答」+「其余维度 · 简略结论」，导出的是这一份。
- 设置收成一行摘要（模型 · 思考档位 · 导出名），点开才是独立设置页，不再把正文挤出一屏。
- 结果按 Markdown 渲染（### 小标题、· 要点、**加粗**），不再是纯文本墙；思考过程单条折叠。
- 今日记录、战略聚焦、日程完成度一起作为上下文；「查看原文」可预览将发送的内容。
- 导出写入每日状态的条目名默认 **反思**。

### 战略聚焦（原「核心聚焦」）
- 改名：核心聚焦 → 战略聚焦；「已完成 · 可撤销」→「已突破」。
- 卡片主标题改为「下一步」（具体要做的事），聚焦维度降为类别标签；勾选只作用于这一条下一步。
- 编辑弹窗字段顺序：下一步 → 聚焦维度 → 完成标准 → 乘数效应。
- 去掉「帝国模块读取键…」「完成后当天仍保留…」两段说明，界面只留数字与内容。
