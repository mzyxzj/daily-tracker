# daily-tracker

本仓库只放源码（lib / pubspec / CI），Android 工程由 CI 里的 `flutter create` 生成。

## 4.6.1 · 更新检查：接口限流就走网页通道（Empire-V4.6.1）

4.6.0 装上去后点「检查更新」直接弹 **「接口返回 403」**，这不是包坏了，是 GitHub 把请求挡了：
`api.github.com` 对**没登录的匿名请求只给每小时 60 次**（按出口 IP 算），手机走运营商 NAT 时
那个 IP 常被别的应用用光，于是 403。旧代码只认 200，一见 403 就死给你看。

### 现在怎么查

```
第一条  api.github.com/repos/…/releases/latest     信息全（说明 + 体积），可能 403
   ↓ 失败
第二条  github.com/…/releases/latest  的 302 跳转    普通网页，没有 60 次限制
        从 Location 里取出 tag → 直接拼 /releases/download/<tag>/app-release.apk
```

第二条是纯网页请求，不碰 API，所以限流打不到它；代价是拿不到更新说明和安装包体积
（弹窗里会标一行「来源：网页通道」）。两条都失败时，提示会同时给出两边的原因，
并且明说是「限流」而不是甩一个 403 数字。

### 顺带

- 错误文案分档：`rate limit` 正文 → 「接口被限流（403，匿名每小时 60 次）」；404 → 「仓库里还没有 Release」；其余原样带状态码。
- 错误弹窗多一段解释，说清为什么会 403、重试会换通道、实在不行去网页下。
- 解析逻辑抽成 `updateErrorHint()` / `tagFromReleaseLocation()` 两个纯函数，`test/update_test.dart` 覆盖 7 条（含 `V4.6.1?x=1#top` 这种带尾巴的 Location）。
- 只动 `lib/app_update.dart` 与版本号，原生注入、数据库、科技树规则全不变。
- 测试 100 条全绿；`flutter analyze` 无 error。

> 已经在 4.5.0 上的人，因为旧代码没有备用通道，**这一次要手动装**：
> 直接下 [app-release.apk](https://github.com/mzyxzj/daily-tracker/releases/download/V4.6.1/app-release.apk)，
> 覆盖安装即可（签名一致，数据不动）。装完 4.6.1 之后就不会再卡在 403 了。

## 4.6.0 · 库只从科技树长出来（Empire-V4.6）

这一版不再让「库」自由生长：**唯一来源是「规划」最上层导图里的 `科技树` 分支**。
分支下面挂什么，侧栏就只有什么；不在分支里的，一律不让它占视线。

### 规则（进入「文化」时自动对齐）

| 情况 | 处理 |
|---|---|
| 在科技树分支下 | 保留，顺序照导图；库里还没有这个节点就自动建（空的也留着，那是待填的坑） |
| 不在分支里，且一条内容都没有 | **直接删掉**（复盘 / 激励 / 内容引进 这类空库会消失） |
| 不在分支里，但还有内容 | **先隐藏**：不进信息流、不在侧栏；等导图里长出同名节点，下次同步自动放出来 |
| `其他` / `未归类` 这类兜底库 | 同上，内容不静默删掉，进「不在科技树里的库」等处置 |

节点名会做归一：`健身常态化（降低皮质醇…）` → `健身常态化`，`一、科技树（复利）` → `科技树`。
库名和节点名允许前缀匹配，所以导图写成「健身常态化」也不会把早就在用的「健身」判成外人。

### 导入：三条路全部卡死

- 侧栏「从剪贴板整理」→ 库选择器只列科技树节点，猜不到就留空，**不选不能存**；
- 剪贴板弹窗点「整理」→ 同样只给科技树节点，导图里没有节点就直接提示先去建；
- 侧栏「手动填一条」→ 不再默认落第一个库 / 「其他」，必须自己指到某一节。

侧栏原来的「新建库」换成了「同步科技树」：库不在这里建，改完规划回来点一下即可。

### 长按：编辑 / 换库 / 删除

库索引页的长按菜单从 2 项补到 5 项：

```
标记看完 / 标记为未看完
收藏 / 取消收藏
编辑标题 / 链接 / 标签
换个库（归到科技树）
删掉这条
```

隐藏库的索引页顶部会有一条提示，长按「换个库」就是归位；归位后旧库空了会被下次同步清掉。

### 隐藏库的处置页

侧栏多一行琥珀色的「N 个库不在科技树里 · M 条」，点进去是收容页，每个库三种处置：

- **逐条归位**：进库索引，长按单条换库；
- **整库并走**：选一个科技树节点，整个库的条目一次改过去，旧库随即删除；
- **连内容删**：确认后连条目一起删（会明确告诉你删几条）。

> 没有把「其他」里的内容直接删掉，是因为那 3 条是真存过的链接；但它已经不在任何入口出现，
> 你点一下「连内容删」或「整库并走」，它就彻底消失。

### 数据与兼容

- 数据库升到 **16**：`culture_libraries` 补 `hidden` / `tree_key` 两列，老库原地升级，条目不动。
- 导图里暂时没有「科技树」节点时，**不删也不藏**，只在侧栏提示，避免误伤。
- 原生注入部分（无障碍、复制即弹、播放器、升级）一行没改。
- 测试 93 条全绿；`flutter analyze` 无 error。

## 4.5.0 · 库索引：标签索引 + 排序即分组（Empire-V4.5）

上一版把库做成了目录，这一版解决「目录怎么翻」：**按标签找**，以及**排序的时候把同类圈在一起**。

### 标签索引

整理面板里填的「标签（空格分隔）」现在会变成库索引页上的一排标签索引：

```
标签   15 个索引                       收起⌃
[训练 5] [增肌 3] [康复 2] [饮食 2] [背 1] [哑铃 1]
[膝盖 1] [核心 1] [拉伸 1] [恢复 1] [器械 1] ...
```

- **不建表**：每次打开这一页，从现有条目的 `tags` 字段现算。整理时改了标签，回来就是新的。
- **一条视频多个标签，就出现在多个标签下面**：统计的是「带这个标签的条数」，不是「唯一归属」。
- **没填标签的归到「无标签」**，不会因为没有标签就消失。
- 一行放不下自动换行（用 `Wrap`，不是横向滚动），标签多的库会排两三行。
- 点任意标签即筛选，再点一次取消；和平台 / 分级 / 类型 / 状态、搜索可以叠加。

> 分隔符除了空格，逗号、顿号、斜杠、分号也认。手滑把一整段备注填进标签栏（超过 14 个字）时不会当成标签，免得索引里出现一整句话。

### 排序就是分组

选哪个排序，就按那个维度切段，段与段之间有一条分隔线（左边档名、中间横线、右边条数）：

| 排序 | 分隔线怎么切 | 分隔线长什么样 |
|---|---|---|
| 最近收录 | 按收录日，一天一段 | `今天 · 8月25日 周一 ───── 3` |
| 最近打开 | 按最后打开日，一天一段 | `昨天 · 8月24日 周日 ───── 2`；从没打开过的单独一段 |
| 打开次数 | 每 5 次一档 | `1–5 次`、`6–10 次`、`11–15 次`；0 次的是「还没打开过」 |
| 按分级 | 一个分级一段 | `绿灯区`、`黄灯区`…；没定级的在最后「未分级」 |
| 按工具包 | 是否已整理成工具包 | `已整理为工具包` / `还没整理` |

时间档的组头会带具体日期和星期，因为「今天」这种写法过两天就看不懂了。日期本身是标题时不重复，只留星期。

「是否已整理为工具包」判断依据是 `culture_kits.item_id`：生成过工具包的条目就算「是」。这一列只查一次，不是每张卡查一遍。

### 顺手改的一处

排序从 4 项变 5 项后，390 宽一行放不下，横滑会把最后一项「按工具包」藏起来——而它是分组开关，看不见等于没有。这一行改成 `Wrap` 换行，5 项全部可见。

数据库不动（仍是 15），没有新表、没有新字段；原生注入部分（无障碍、复制即弹、播放器、升级）一行没改。

## 4.4.0 · 库索引页：点库名进去，一页看完这个库收了什么（Empire-V4.4）

以前侧栏的「库」只是一行计数，点不动；想找一条三个月前存的，只能在信息流里一直往下刷，
而信息流为了「现在该看哪一条」会把已看完的过滤掉——于是那些内容就再也找不回来了。

现在点侧栏任意库名（健身 / 家庭 / AI …）会进入这个库的**索引页**，布局照 B站 索引：
顶部排序，往下几行维度筛选，下面是封面网格，**所有收录过的都在**，包括已经看完的。

### 页面结构

```
←  🏋️ 健身                      🔍
   12 条 · 未看 7 · 看完 1 · 备注

排序   最近收录  最近打开  打开最多  按分级        收起⌃
平台   全部  B站  抖音  小红书  YouTube
分级   全部  绿灯区  黄灯区  橙灯区  红灯区
类型   全部  视频  图文
状态   全部  未看  看过  已看完  收藏
12 条                              点开就看 · 长按整理

┌────┐ ┌────┐ ┌────┐
│封面 │ │封面 │ │封面 │     ← 3 列，窄屏 2 列，平板更多
└────┘ └────┘ └────┘
标题两行……
备注或作者
```

### 卡片上有什么

| 位置 | 内容 |
|---|---|
| 左上 | 平台色标（B站粉 / 抖音黑 / 小红书红…） |
| 右上 | ⭐ 收藏、`✓ 看完` 角标 |
| 右下 | 时长；没有时长就显示打开过几次 |
| 封面 | 有图直接铺；没图用平台渐变 + 标题首字，不留白块 |
| 已看完 | 整张压暗 + 标题变灰，一眼和没看的分开 |

点卡片直接进 `CulturePlayerPage`（还是那套站内播放器，带清晰度）；
**长按**可以标记看完 / 恢复未看完、收藏 / 取消收藏——不用再回信息流去点。

### 几个实现上的取舍

- **维度全部来自本地真有的字段**：平台（`platform`）、分级（`grade_tier`）、类型（`kind`）、
  状态（`state` / `fav`）。B站 那套「地区 / 风格 / 付费类型」在这里没有对应数据，
  硬造只会得到一排永远 0 条的筛选。
- **筛选行按需出现**：平台只有 1 种、类型全是「视频」时不显示那一行，免得空占地方；
  点右上「收起」可以把除排序外的行折起来，给小屏腾高度。
- **排序里「最近打开」把从没打开过的排最后**，不是按 id 混进去——否则一开库全是没看过的，
  「最近打开」就没意义了。
- **标题区用 `Expanded + ClipRect`**：系统字体放大到 1.5 倍时只压缩标题，不会撑破网格
  （撑破在真机上是一条黄黑警示条）。
- **不需要改表**：只读 `culture_items`，schema 仍是 15。打开条目走的还是 `CultureDb.touchItem`，
  `state 0 → 1`，所以「未看」筛选会实时少一条。

## 4.3.1 · 清晰度补到独立播放器 + 弹窗不再重复打扰（Empire-V4.3）

### 1. 清晰度按钮：独立播放器页也有了

4.3.0 只把清晰度加在了信息流里的内嵌播放器，而「在这里看」打开的是
`CulturePlayerPage`（另一套 WebView），所以那一页看不到按钮。

现在两处都有：信息流里的内嵌播放器在左下角，独立播放器页在**右上角常驻一个档位胶囊**
（不跟顶部/底部浮层一起隐藏，收起操作条也还在）。点开选档，切换后保持播放。
只在 `kind == 'bili'` 时出现——抖音官方播放页没有可调档位。

切换走两条路：先调 `player.setQuality(q)`（无缝、不中断）；调不动（老播放器或对象没暴露）时，
用播放器页自己支持的 `?quality=` 参数重载，重载前记下 `currentTime`，加载后 1.8s 跳回去。
`_reloadedForQuality` 保证一次切换只重载一次，否则 `onPageFinished` 会再套用一次、无限重载。

### 2. 点了「整理」进 App 又弹一次

原因：App 打开后页面渲染会产生 `TYPE_WINDOW_CONTENT_CHANGED`，而 15 秒内还在
「内容类 App 上下文」里，于是服务又读一次剪贴板（这次 App 在前台，读得到），
文本与上次盲弹的空内容不同 → 又弹。

三处修正：

- 事件来源是自己包名时直接 `return`，连上下文都不更新；
- 新增 `consumedAt`：点「整理」或「略过」后 30 秒内不再弹；
- `MainActivity.consumeIntent` / `ClipPromptActivity.openIntake` / 悬浮条按钮都调 `markConsumed()`。

### 3. 只在「复制外链」时弹

之前只要点到文字含「复制」的控件就弹，微信里长按消息点「复制」也会命中。现在按置信度分级：

| 置信度 | 判定 | 行为 |
|---|---|---|
| 2 | 「复制链接 / 复制地址 / 复制分享 / Copy link」 | 任何 App 里都算 |
| 1 | 只写「复制 / Copy / 拷贝」 | 只在 B站/抖音/小红书/快手/微博/知乎/YouTube 里算 |
| 0 | 其他 | 不算 |

微信、QQ 故意不在「复制即链接」的白名单里——它们的「复制」是复制聊天文字。

## 4.3.0 · 复制即弹真正修通了 + 清晰度调节 + 穿透 shadow DOM（Empire-V4.3）

### 1. 「复制链接没反应」：找到根因了

前面两版都在改「怎么弹」（悬浮窗 → 透明 Activity），但真正的问题在**根本不该被触发**：

```kotlin
// V4.2 的逻辑
if (clipApiOk) return            // 剪贴板回调一旦"成功"过，事件就全被丢掉
...
if (reason != "click" && reason != "clip") return   // 事件路径永远走不进盲弹
```

`addPrimaryClipChangedListener` 在 Android 10+ **只在应用有焦点时派发**。无障碍服务在后台，
回调根本不来，于是 `clipApiOk` 一直是 false；而事件路径读剪贴板又被系统拒绝（返回空），
空内容 + `reason="event"` 直接 return —— 结果就是**点了复制，代码一行都没执行到弹窗**。
这不是 ColorOS 的问题，是所有 Android 10+ 都会这样。

现在改成三条**不依赖读取剪贴板权限**的信号：

| 信号 | 来源 | 为什么可靠 |
|---|---|---|
| 点到了「复制链接 / 复制 / Copy」控件 | `TYPE_VIEW_CLICKED` + `node.text/contentDescription` | B站、抖音分享面板都是标准按钮 |
| 系统 Toast「已复制 / 复制成功」 | `TYPE_NOTIFICATION_STATE_CHANGED` | 复制成功的自绘气泡多数 ROM 只回这个 |
| 窗口内容变化 | `TYPE_WINDOW_CONTENT_CHANGED` | 兜底，延迟 300ms 再读一次 |

读到内容就带预览弹；读不到（被 ROM 拦）也照弹，点「整理」App 到前台再读。

### 2. 弹窗三条通道，谁通谁上

ColorOS 的「后台弹出界面」关着时，`startActivity` **不抛异常也不显示**，光靠 try/catch 永远发现不了。
现在 Activity 启动后 700ms 检查 `onResume` 回执：

- 回执到了 → 提示卡显示成功，结束；
- 没回执 → 改发**通知**（不需要后台弹窗权限），通知也没权限 → 退**无障碍悬浮窗**；
- 三条全失败 → 自检面板直接写「提示通道全被拦」。

通知需要 `POST_NOTIFICATIONS`（Android 13+ 运行时权限），所以打开自检面板时会自动申请一次。

### 3. 清晰度调节

B站 播放器左下角新增清晰度按钮（自动 / 4K / 1080P60 / 1080P / 720P / 480P / 360P），
直接调播放器实例的 `setQuality()`，切换后自动接着播。

- 档位是 B站 自己给的：未登录通常只有 480P / 360P，登录后才到 1080P；
- 抖音官方播放页由平台决定码率，没有可调档位，这个按钮不显示。

### 4. 播放：穿透 shadow DOM

B站 新版播放器是 `<bwp-video>` 自定义元素，真正的 `<video>` 在它的 `shadowRoot` 里。
`document.querySelector('video')` 返回 null，于是「滑到即播」实际什么都没做。现在改成递归遍历
shadow root 找 video，播放 / 暂停 / 探测全部走同一条路径。

另外补了黑屏探测：3.5s / 7.5s 各看一次 `videoWidth`，连续两次为 0 就自动换下一个源
（黑屏不会触发 `onWebResourceError`，这是唯一能识别出来的办法）。

## 4.2.0 · 复制即弹换了实现 + 滑到即播 + 应用内升级（Empire-V4.2）

### 1. 复制了没反应：不再用悬浮窗，改成透明 Activity

4.1 的自检面板在一加 13T 上显示「弹过悬浮条 25 秒前」，但屏幕上什么都没有。
原因：`TYPE_APPLICATION_OVERLAY` / `TYPE_ACCESSIBILITY_OVERLAY` 在 ColorOS / 氧OS 上
`addView` 会成功返回、窗口却不可见，日志一切正常。

现在换成 `ClipPromptActivity`（透明主题的真实窗口）：

- 拿「显示在其他应用上层」权限后，Android 10+ 允许它从后台起界面，盖在 B站/抖音 上面；
- 12 秒自动消失，点空白处消失，「整理」直接把链接交回 App；
- 复制到链接时**先振动一下**，视觉被吞也能感知；
- 启动失败（ColorOS「后台弹出界面」关着）会把原因写进自检面板的「底层报错」，不再静默。

### 2. 滑到哪就播哪，不用点两下

流里的视频条目现在直接在卡片里挂 WebView：滑到这一页自动播放，滑走就暂停、页面销毁一起回收。
关键一步是关掉 WebView 的「必须用户手势」限制（`setMediaPlaybackRequiresUserGesture(false)`），
否则自动播放会被静默拦掉，表现为「画面在、就是不动」。
播放器页做三级换源，加载完把 `video` 拉满全屏并补一次 `play()`（失败再静音重试）。

### 3. 全屏按钮真的能全屏了

B站播放器自带的那个全屏按钮在 WebView 里无效（JS fullscreen 需要宿主实现 `onShowCustomView`，

## 4.1.0 · 修两个「明明做了却没生效」（Empire-V4.1）

### 1. 播放器：不再加载「打开App」的落地页

4.0 的内置播放器直接把 `m.bilibili.com/video/BVxxx` 塞进 WebView。那是手机浏览器的
**落地页**，整页都在劝你「打开App，流畅又高清」，点一下就跳出 App —— 等于没做站内播放。

现在改成先翻译地址（`lib/player_target.dart`）：

| 平台 | 加载什么 | 为什么 |
| --- | --- | --- |
| B站 | `bilibili.com/blackboard/html5mobileplayer.html?bvid=…` | B站自己的移动版 HTML5 播放器页，只有播放器，没有任何 App 引导 |
| B站（备用） | `player.bilibili.com/player.html?bvid=…` | 官方 iframe 播放器，主地址没出画面时自动切 |
| B站（兜底） | `www.bilibili.com/video/BV…`（桌面 UA） | 新版播放器取流最稳，两个移动源都被挡时才用 |
| 抖音 | `open.douyin.com/player/video?vid=…` | 开放平台播放器；不行再退分享页 |
| 其它 | 原链接 | 不动 |

- `b23.tv` / `v.douyin.com` 短链会先跟一次 302 拿到 BV / aweme id 再拼地址。
- UA 去掉 `wv` 标记（带这个标记会被一些站点直接判成内嵌浏览器并强制跳 App）。
- `bilibili://`、`snssdk1123://`、`intent://` 这类跳 App 的 scheme 一律拦下并提示已拦。
- 加载完会探一次 DOM 有没有 `video / bwp-video`（B站放在 shadow DOM 里）：没有就逐级换源，三级都不行才显示兜底卡
  （兜底卡给「换个源再试 / 登录 / 生成工具包 / 复制链接」，不再直接把你踢出去）。
- 登录页跳回站内后**自动回到这条视频**，不用手动退。

### 2. 复制即弹：为什么之前不弹，这次怎么修的

现象是「复制了，屏幕上方什么都不出现，必须切回 App 才弹」。三个真实原因，逐个堵：

1. **服务被系统停了**。MIUI / HyperOS 会在后台掐掉无障碍服务，但系统设置里的开关
   还是「开」。4.0 只查了开关，所以侧边栏一直显示「已开启」，实际早死了。
   → 现在分开看 `enabled`（开关）和 `connected`（服务进程是否在跑），
   三态显示：未开启 / 已开启但服务被停 / 正常。
2. **只监听「窗口切换」**。B站/抖音的「复制成功」是自绘气泡，多数 ROM 只回
   `TYPE_WINDOW_CONTENT_CHANGED`，甚至只有剪贴板回调。4.0 的代码把 content changed
   过滤掉了，所以整片漏掉。
   → 事件类型给全（`typeAllMask`，服务启动后再用 `setServiceInfo` 动态设一遍），
   剪贴板回调 + 事件兜底双路。
3. **系统不让后台读剪贴板**。小米/OPPO/vivo 的剪贴板保护会让 `getPrimaryClip()` 返回空，
   4.0 直接 `return`，所以什么都不弹。
   → 现在读不到内容也照弹，只是不带预览（「复制了内容 · 要整理进文化吗？」）；
   点「整理」App 到前台再读一次，前台一定读得到。为了不乱弹，只在内容类 App
   （B站/抖音/小红书/微信/浏览器…）且 8 秒内还在内容场景时才走这条路。

另外：
- 悬浮条优先用 `TYPE_APPLICATION_OVERLAY`（有「显示在其他应用上层」时更稳），
  没授权自动退回无障碍专属窗口。两种都失败会记下原因，不静默。
- 侧边栏那张卡点进去是**自检面板**：无障碍开关 / 服务是否在跑 / 悬浮条权限 /
  最近一次系统事件 / 最近读到剪贴板 / 最近弹条 / 底层报错，还有「试一下」按钮
  立刻弹一条示例验证。以后反馈「不弹」直接看这一屏就能定位。
- 为了不触发太多次 Android 12+ 的「已粘贴」系统提示：剪贴板回调一旦确认可用，
  就不再靠无障碍事件重复读。

### 3. 签名固定了：以后升级不用卸载

之前每个版本的 APK 都用 `flutter create` 模板里的 debug 签名，而 CI 每次 runner 的
debug keystore 都是新生成的 —— 签名一变，覆盖安装必失败，卸掉重装数据就全没了。

现在 `.android-inject/dt-release.jks` 是仓库里一把固定密钥，`patch.py` 会把它拷进
`android/app/` 并让 release 用它签名。**从这一版起，之后的版本都能直接覆盖升级。**

代价：这一版和之前 CI 出的包签名不同，**装之前要先卸载旧版**（数据会清空）。
卸载前如果库里有舍不得的条目，先在「文化 → 侧边栏 → 库」里截图或抄一下链接。

**需要你做的一次性动作**：设置 → 无障碍 → 「文化 · 复制即整理」打开。
小米/OPPO 建议再给一个「显示在其他应用上层」；如果自检里「服务是否在跑」是「没连上」，
把它关掉再打开一次即可。

- **至少能存链接、能打开**：一条内容 = 链接 + 一句话标题（粘贴自动拆 URL 和标题），
  平台从域名识别（B站 / 抖音 / YouTube / 小红书 / 公众号 / 知乎 / GitHub / 微博 / X / Notion）。
- **两种信息流**：B 站式横版卡（16:9 封面 + 两行标题 + 时长 + 平台），抖音式竖版两列
  （9:16 封面为主）；再加一个紧凑列表。封面填 URL 就用图，不填用平台色渐变 + 首字兜底。
- **10 秒找到**：搜索框输入即筛（标题 / 标签 / 来源 / 备注 / 链接），筛选「全部 / 未看 /
  收藏 / 看过」，排序规则是收藏 > 未看 > 打开次数 > 最近打开。点卡片直接打开，
  不先进详情页。

## 2.5.4 · 聚焦去重 + 模板可编辑（Empire-V1.3）

### 战略聚焦为什么会重复
`FutureBuilder(future: _load())` 写在 `build` 里，任何一次 `setState`（勾选、记笔记、折叠）
都会新建一个 Future；几条 `_load()` 并发跑「未完成顺延」，都先查「今天有没有这条」→ 都查到
空 → 各插一条，于是同一条聚焦出现 2～4 份。

四层修复：
1. **加载复用**：`_load()` 对同一日期复用在飞的 Future（`_loadingFuture` / `_loadingDate`），
   顺延逻辑不再并发执行；日期切换才重开。
2. **去重键修正**：顺延判重从「标题」改成「维度 + 下一步」。原来的键是维度，同维度下的
   多个不同下一步会被误判成同一条而丢掉。
3. **插入幂等**：`ConflictAlgorithm.ignore` + 每处理一条立刻置 `rolled = 1`，缩小窗口。
4. **库层兜底**：DB 版本 9 → 10，升级时 `AppDatabase.dedupeFocusItems()` 按
   `(date, title, next_step)` 合并历史重复（已勾选的优先保留、较长的备注并过去），
   再建唯一索引 `idx_focus_unique`。手动新增重复项改为合并并 SnackBar 提示。

### 模板全部可编辑
- 4 条内置模板首次运行并入 `ui_states.deepseek_presets`，与自定义模板同等对待：
  可改名、改角色、改指令、删除（删除有二次确认）。
- 管理页底部新增「恢复内置」，删错了能一键补回；「新建预设」用当前角色 + 指令存一条。
- `deepseek_presets_seeded` 标记保证内置模板只并入一次，删掉后不会下次启动又出现。
- 菜单标题改为「模板 · 可编辑」，避免「内置 = 只读」的误解。

## 2.5.3 · 反思指令外置 + 预设可编辑（Empire-V1.2）

### 首轮正文只发数据
`_firstPayload()` 末尾那段「请据此做今日反思：先给 3 条核心判断；再分板块分析…」已删除。
现在「将发送给 DeepSeek 的内容」只有三段：`【日期】` / `【今日记录】` / `【战略聚焦】`。
预览弹窗底部会显示当前生效的角色与预设名，避免「看不到指令」的疑惑。

### 分析方式收进角色与指令
- 默认角色：`第一性原理复盘官`。
- 默认指令（`kDefaultPrompt`）写死了输出骨架：
  1. 3 条核心判断，每行 ≤30 字，必须是明天可验证的事实判断；
  2. `### 精力与执行的错配` —— 峰谷时段、难任务位置、代价、纠偏；
  3. `### 战略聚焦的推进实况` —— 逐项：推进到哪步 / 是否达标准 / 卡在能力还是时间；
  4. `### 系统性风险` —— 只挑连续三天会崩的结构性隐患，写触发条件；
  5. `### 明日最小动作` —— 恰好 3 条，≤30 分钟，带时间点与完成判据。
- 数字要给具体值与方向，没记录写「未记录」，不要猜。
- 老配置自动升级：文本等于 `kLegacyPrompt` 或 `kV11Prompt` 时替换为新默认。

### 预设
- 内置 4 条只读模板：帝国日课复盘（默认）/ 代谢与营养精算师 / 精力与执行教练 / 战略聚焦推进官。
- 「保存当前为预设…」把当前角色 + 指令存进 `ui_states.deepseek_presets`（同名覆盖）。
- 「管理我的预设…」支持改名、改角色、改指令、删除、点击整行直接套用。
- 套用后会立刻写回 `deepseek_ai_config`，下次打开面板自动带出上次用的那套。

## 2.3.0 · 帝国模块进主界面

### 模块结构
帝国与「查找 / 家庭 / 今日 / 规划」同一层级，作为底部第 4 个 Tab（`lib/empire_page.dart`）。

- **主模块页**：整屏只留一个 3D 领地 + 两张关键参数子模块 + 一框三条纪事。
  - 领地：`lib/empire_assets.dart` 里内嵌的 L07 渲染图（640×640 WebP，由已生成的 GLB 离线渲出），缓慢浮动 + 落地投影；顶部等级胶囊、右上复利乘数、底部距下一级进度。
  - 繁荣度子模块：大数字 + 十年曲线缩略 + 日均增量，点进去是详情页。
  - 乘数效应子模块：复合乘数 + 六维构成色条 + 突破项数，点进去是对比页。
  - 纪事：卡片只留最近 3 条（小字、色标区分战争/晋升/突破），点开是全部 47+ 条。
- **繁荣度页**：领地平面图（九级台地 / 六分区 / 主街 / 建筑群 / L07 界线）+ 成长曲线
  （30 天 / 90 天 / 1 年 / 3 年 / 10 年，自动或对数轴，等级线与穿越点）+ 九级形态进程条。
- **乘数效应页**：六维总乘数横向对比（条长按增量比例），点某个维度就展开该维度
  **最新已突破的下一步**（完成标准、日期、乘数），其余维度淡出到 40%；下方补最近 5 条突破。

### 口径（`lib/empire_data.dart`）
- 每日基础流量 500 × 当日连乘，按 3650 天推演 → 繁荣度曲线与九级门槛（×5 递增）。
- 维度总乘数 = 该维度下所有「已突破」下一步的乘数逐个相乘；复合乘数 = 六个维度总乘数再相乘。
- 只统计 `focus_items` 里 `done = 1` 的条目；取消勾选会自动退回。
- 本地还没有「已突破」条目时，用 `lib/empire_assets.dart` 内嵌的示例数据撑起界面，页头标「示例推演」。
- 每次切到帝国 Tab 或下拉刷新都会重新读库。
